# 額面火力指数・額面モデル


モデル: face-value-0.6-local-r2。

最終式は `(物理攻撃力 + 属性値) × 武器SP倍率 × ダメージ倍率`。
通常属性は弱点設定によらず加算。毒・麻痺・睡眠・爆破の蓄積値は加算しない。
武器固有補正、独立会心倍率、状態異常補正、肉質、モーション値は対象外。

## 基本式と前提

物理は `floor((武器攻撃 × (1 + 攻撃倍率カテゴリ合計) + 攻撃加算 + 漂移攻撃加算) × 攻撃活性)`。
2026-10-24更新の①・②個別記事を優先し、途中では切捨てず攻撃活性後に一度切捨てる。カテゴリ抜粋・③記事の途中切捨てとの矛盾は未解決。
既存対応の連撃・守勢・火事場力は同カテゴリ加算。条件稼働率で上昇率を重み付けする既存の近似を維持（条件相関や厳密な時間積分ではない）。

属性は会心状態ごとに `floor((武器属性 × 会心撃倍率 + 属性攻撃加算) × 古龍属性倍率)` を計算して確率平均。弱点倍率は適用しない。
会心撃は正会心時のみ武器属性へ適用。通常会心・超会心の最終倍率は掛けない。会心率設定と弱点特効/力の解放稼働率は会心撃の発動確率に残る。
古龍対応: 鋼龍の凍風・幻獣の疾雷・溟龍の波雷・爵銀龍の紅血・冰龍の冰纏。属性が合う場合のみ適用。複数該当する場合は重複規則未確定として候補を評価対象外にする。検索を継続し、Workerから除外理由を返して結果先頭へ表示。内部順位付け用の負値は正常結果に出さず、0点としない。
スタイル数値加算は未対応のまま明示。Lv10技能の解放選択は保持。

通常攻撃はSP倍率1。SPは手動区分でLv1/G6未満=1、Lv2/G6–7=1.05、Lv3/G8以上=1.10。選択値は保存・検索スナップショットへ含む。武器グレードから自動推定せず、カスタム武器も同じ明示指定。
ダメージ倍率は既存対応スキルの乗算構造と稼働率を維持。SP威力アップはSP区分だけ適用。SP境地は重複規則の確認まで未対応・加点なし。異なる既存ダメージスキルの重複規則は既存乗算を維持しており、資料で確定したとは扱わない。
未対応のスキルは従来どおり加点なし表示。すべてのスキル対応を意味しない。

旧弱点/属性倍率設定はバックアップ互換のため保持するが隠して無効化し、額面指数には使用しない。保存済み旧モデルのスコアは履歴として保持し、再検索が必要。
ランキングと詳細は同じWorkerの計算結果を使用。内訳には基本物理・属性、SP倍率、ダメージ倍率、最終式を表示。
