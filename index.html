簡単な操作法
最短手順: ①武器を選ぶ → ②必要なら発動率/漂移を調整 → ③「最大威力構成を検索」 → ④上位構成を開く → ⑤マイセット保存。

1. 最大威力ランキング

  1. 「最大威力」タブで「絞り込み選択」を押し、武器種・属性・素材元・名称で絞って武器を選びます。攻撃力・会心・属性値は手入力で上書きできます。
  2. 弱点属性なら「弱点属性として計算」をONにします。
  3. 弱点特効・連撃など、常時発動しないスキルは「発動率・立ち回り」で実戦の割合に合わせます。
  4. 漂移錬成は「なし / 自動最適化 / 指定加算」から選択します。
  5. 検索後、行をタップすると装備・スキル・計算内訳・入手先を確認できます。

2. スキル指定検索

  1. 「スキル指定」タブでは一覧からチェックしてスキルを選び、右側でLvを指定します。文字検索・カテゴリ絞り込みも使えます。
  2. 複数条件を追加して「条件を満たす構成を検索」。武器スキルと漂移錬成も合算します。

3. 比較・除外・マイセット

  • 構成詳細の「比較に追加」で最大3構成を横並び比較できます。
  • 防具の「除外」を押すと、以後の検索候補から外れます。「除外・データ」タブで解除できます。
  • 「マイセット登録」でブラウザ内に保存します。データはこの端末/ブラウザの localStorage に保持されます。

4. 素材・入手先

  1. 気に入った構成をマイセットへ登録します。
  2. 「素材」タブでマイセットを選び集計します。
  3. 必要個数がマスター登録済みの素材は合算、未登録装備は関連モンスター/公式参照先を表示します。

5. iPhone / iPad でアプリ化

  1. このPWAを HTTPSのURL からSafariで開きます。
  2. Safariの共有ボタンを押し、「ホーム画面に追加」を選びます。
  3. ホーム画面の MHN Build Lab アイコンから起動します。一度オンラインで起動後、主要画面はオフラインでも利用できます。
HTMLファイルを「ファイル」アプリから直接開く方法ではPWAのオフライン機能は有効になりません。Webサーバーへ配置してHTTPSで開いてください。

6. バックアップ

  • 「バックアップ」は対応端末ではiOSの共有シートを開き、JSONを「ファイルに保存」等へ渡せます。
  • 共有シート非対応環境では通常のJSONダウンロードに自動で切り替わります。
  • 「読込」で復元できます。外部装備マスターは「除外・データ」から読み込みます。

計算上の注意

火力指数は「攻撃力＋弱点時属性値」を軸に、会心・属性会心・攻撃系スキル・指定発動率を期待値化した比較指標です。武器固有のモーション値、弾/矢、砲撃、スタイル、部位肉質、状態異常蓄積などはまだ完全な実DPS計算ではありません。
